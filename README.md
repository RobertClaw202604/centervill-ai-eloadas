# Centervill — AI előadás ajánlat (mini web)

Ajánlat és tematikai javaslat a Centervill Kft. 2026. december 16-i év végi rendezvényére
(Domonyvölgy, 80 fő, 45 perces AI előadás).

- `index.html` — a teljes oldal (egyfájlos, nincs build)
- `assets/` — generált és letöltött képek (hero, terep, iroda, modell, karácsony, Centervill logó)
- GitHub Pages: https://robertclaw202604.github.io/centervill-ai-eloadas/

## Szekciók
1. Hero — villamos szikra-hálózat canvas animáció
2. A felkérés (levélkivonat + négy kérés / négy válasz)
3. Tematika — 5 felvonás
4. DarwinAI 6+1 modell (7 kártya)
5. Centervill-példák: iroda és terep
6. Karácsonyi blokk — hópelyhes animáció
7. Napirend — animált idővonal-sávok
8. Mit visznek haza
9. Ajánlat + kapcsolat
